# Word Master Support

If you run into an issue with the iOS release of Word Master, use one of the following channels:

- Support email: injooinjoo@gmail.com
- GitHub issues: https://github.com/injooinjoo/word_master/issues
- Repository homepage: https://github.com/injooinjoo/word_master

When reporting an issue, include:

- Device model
- iOS or iPadOS version
- App version
- What screen you were on
- What happened just before the issue

The iPhone and iPad release starts in guest study mode by default and also offers optional email login from the result screen.
