# App Privacy Answers

Target build: first iOS App Store release with guest mode by default and optional email login

- Data collected from this app: Yes, only if the user signs in
- Tracking used: No
- Account creation required: No
- Advertising SDK included: No
- Remote analytics enabled: No

Local-only data used inside the app:

- Quiz history
- Adaptive difficulty state
- Audio preference settings
- Character profile preferences

Remote data used only for signed-in users:

- Email address
- Quiz answer history and adaptive learning progress
- Character profile preferences
